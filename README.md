# Sheikh Afaan Farooq — Resume Website

A responsive personal academic and research profile website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and footer year

## Publish using GitHub Pages
1. Create a new public repository on GitHub, for example `afaan-farooq-resume`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub Pages finishes publishing, the site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/afaan-farooq-resume/`

For a user-site URL such as `https://YOUR-GITHUB-USERNAME.github.io/`, name the repository exactly `YOUR-GITHUB-USERNAME.github.io`.

## Before publishing — please review
- Confirm the exact official PhD programme/institution and expected completion date.
- Confirm education titles and dates.
- Verify the publication totals and whether the registered intellectual-property item should be called a patent or registered design.
- Add your LinkedIn profile URL if you want it displayed.
- Add a CV PDF to `assets/` and link it from the hero section if desired.
- The website does not claim hands-on experience with unconfirmed frameworks such as PyTorch, TensorFlow, React, or cloud platforms.
